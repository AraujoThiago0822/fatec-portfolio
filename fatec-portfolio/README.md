# Portfólio — Desenvolvimento Multiplataforma

Projeto React (Vite) para o portfólio individual da Fatec, com página mestra e uma tela dedicada para cada projeto.

## O que editar primeiro

1. `src/data/profile.js` — seus dados pessoais, formação, experiência, cursos e idiomas.
2. `src/data/projects.js` — dados dos 6 projetos (troque os links do GitHub, ajuste descrições).
3. `public/profile.jpg` — sua foto (ainda não usada no layout atual, veja o tutorial para adicionar).
4. `public/projects/<slug>/` — screenshots de cada projeto.

Veja o `TUTORIAL.md` (na raiz do pacote entregue) para o passo a passo completo, incluindo os comandos de terminal e o deploy na Vercel.

## Comandos

```bash
npm install     # instala as dependências
npm run dev     # inicia em modo desenvolvimento (http://localhost:5173)
npm run build   # gera a versão de produção em /dist
npm run preview # testa a versão de produção localmente
```
