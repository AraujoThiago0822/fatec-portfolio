# Portfólio — Desenvolvimento Multiplataforma

Projeto React (Vite) para o portfólio individual da Fatec, com página mestra e uma tela dedicada para cada projeto.


## Comandos

```bash
npm install     # instala as dependências
npm run dev     # inicia em modo desenvolvimento (http://localhost:5173)
npm run build   # gera a versão de produção em /dist
npm run preview # testa a versão de produção localmente
```
